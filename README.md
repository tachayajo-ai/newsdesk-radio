# Newsdesk Radio

รวมลิงก์สำนักข่าวที่อ่านได้ฟรี (ไทย ต่างประเทศ เอเชีย ธุรกิจ เทคโนโลยี การแพทย์) ช่องทีวีดูสดฟรี และวิทยุออนไลน์ทั่วโลก ในหน้าเว็บเดียว

- ข่าว: กดโลโก้เพื่อเปิดเว็บสำนักข่าว ปักหมุดสำนักที่ใช้ประจำได้
- ทีวี: ช่องทีวีไทยและช่องข่าวต่างประเทศที่ดูสดฟรีจากเว็บทางการของแต่ละช่อง
- วิทยุ: ค้นหาสถานีจาก [Radio Browser](https://www.radio-browser.info) กว่า 50,000 สถานี เลือกประเทศ แนวเพลง กรองเฉพาะสถานี AM และเก็บสถานีโปรดได้

เปิดใช้งานผ่าน GitHub Pages หรือดับเบิลคลิก `index.html` ในเครื่อง

## ข้อจำกัดความรับผิดชอบ

- โปรเจกต์ส่วนตัว ไม่แสวงหากำไร ไม่มีโฆษณา ไม่เก็บข้อมูลผู้ใช้ (ค่าที่ตั้งไว้เก็บใน localStorage ของเบราว์เซอร์เท่านั้น)
- ไม่ได้โฮสต์ ดาวน์โหลด หรือ restream เนื้อหาใดๆ: ข่าวและทีวีเป็นลิงก์ไปเว็บทางการ วิทยุเล่นจาก URL สตรีมที่ Radio Browser เผยแพร่
- ชื่อ โลโก้ และเครื่องหมายการค้าเป็นของเจ้าของแต่ละราย หากต้องการให้นำลิงก์ออก เปิด Issue ได้เลย
