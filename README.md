# Newsdesk Radio

รวมลิงก์สำนักข่าวที่อ่านได้ฟรี (ไทย ต่างประเทศ เอเชีย ธุรกิจ เทคโนโลยี การแพทย์) และวิทยุออนไลน์ทั่วโลก ในหน้าเว็บเดียว

- ข่าว: กดโลโก้เพื่อเปิดเว็บสำนักข่าว ปักหมุดสำนักที่ใช้ประจำได้
- วิทยุ: ค้นหาสถานีจาก [Radio Browser](https://www.radio-browser.info) กว่า 50,000 สถานี เลือกประเทศ แนวเพลง และเก็บสถานีโปรดได้

เปิดใช้งานผ่าน GitHub Pages หรือดับเบิลคลิก `index.html` ในเครื่อง
